# Issue tracker: Linear

Use the Finite Computer Linear workspace for issues, product specifications,
decisions, and follow-up work. GitHub hosts code, pull requests, and releases.

- Read the relevant Linear issue and its comments before implementing it.
- When a skill says "publish to the issue tracker," use Linear. Keep plans and
  acceptance criteria there and link the issue from the implementation PR.
- Use Linear relationships for parent issues, sub-issues, and dependencies.
- Read historical GitHub issues when referenced; keep new work in Linear.
- Resolve identifiers explicitly: `FIN-123` is a Linear issue; GitHub issue and
  PR numbers belong to their named repository.
